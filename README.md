# Groundwork

A private, single-user spending and recovery tracker. Enter an amount, add a description, then record it as **SPENT** or **MADE**. The balance is calculated from the transaction history.

## Run it

Open `index.html` in a modern browser. There is no build step, account, server, or bank connection. Transactions are saved in that browser's local storage and stay on that device.

## Files

- `index.html` — page structure
- `style.css` — responsive visual design
- `script.js` — keypad, transaction history, balance and local storage

Use **RESET DATA** below the history to remove all entries after confirming. Each individual transaction also has a confirmed delete action.
